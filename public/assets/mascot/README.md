# 小云朵动作素材

这组四张图沿用 `mascot-main.png` 的形象，保存为透明 RGBA 4×2 atlas，并接入首页云朵：

- `mascot-expressions-atlas-v1.png`：平静、闭眼笑、害羞、疑惑、叹气、轻微生气、惊讶、睡觉。
- `mascot-tap-frames-v1.png`：抬起、压扁、回弹和左右轻晃等点击帧。
- `mascot-cash-frames-v1.png`：掏钱、钱飞走、接钱、塞回云朵等收支帧。
- `mascot-pop-frames-v1.png`：第七次点击时云朵轻轻散成棉花团的 8 帧动作。
- `stop-sign-v1.png`：透明的日文「止まれ」路牌素材，用于云朵爆开后的互动恢复。

表情图集的第 7、8 帧用于雷雨与深夜。深夜帧自带睡帽，界面只补充轻轻上浮的 z，避免重复戴帽子。

`src/PocketMascot.jsx` 把格子裁成独立的 nested SVG。每次点击使用对应的完整表情素材，稳定时只显示一个云朵；表情交接为 100ms，回弹、呼吸和动作位移由 `transform`、`opacity` 和 Web Animations 连续插值。叹气改成矢量云朵与嘴边三股缓慢散开的气流，去掉眼睛附近的水滴。生气帧右上角的小符号单独裁出微动，最后两次点击保持相同的轻微生气表情。

路牌从顶部落下后，第一次点击小幅推摇，第二次加大幅度，第三次平滑淡出并让云朵一次显现；七秒自动回归走同一条退场路径。路牌使用 `transform`、`opacity` 和可中断的 WAAPI，不再播放旧的多帧跳动回弹。爆开动作使用保持微怒表情的连续棉花路径，不再闪过笑脸。

收支图集同时保存了完整分镜。运行时只裁出其中的钱束素材，沿连续曲线飞出或接住；哭脸、眼泪和手势保持独立动画。支出为 860ms，收入为 1040ms，不叠加第二张云朵或第二捆钱。

素材由内置 `image_gen` 生成，随后移除生成器烘焙的中性棋盘格并保留真实透明通道。不要把整张 atlas 当作按钮背景，也不要在图片里写入金额、文案或业务状态。

验证：`node tests/mascot-motion.browser.cjs` 覆盖表情可见性、叹气气流、连续棉花散开、路牌两次渐强推摇、第三次平滑还原、眼泪运动、天气配件、快速连点、自动还原和卸载清理。手机确认按钮另见 `tests/confirm-touch.browser.cjs`。
