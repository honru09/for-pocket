# 小云朵动作素材

这组四张图沿用 `mascot-main.png` 的形象，保存为透明 RGBA 4×2 atlas，并接入首页云朵：

- `mascot-expressions-atlas-v1.png`：平静、闭眼笑、害羞、疑惑、叹气、轻微生气、惊讶、睡觉。
- `mascot-tap-frames-v1.png`：抬起、压扁、回弹和左右轻晃等点击帧。
- `mascot-cash-frames-v1.png`：掏钱、钱飞走、接钱、塞回云朵等收支帧。
- `mascot-pop-frames-v1.png`：第七次点击时云朵轻轻散成棉花团的 8 帧动作。

表情图集的第 7、8 帧用于雷雨与深夜。深夜帧自带睡帽，界面只补充轻轻上浮的 z，避免重复戴帽子。

`src/PocketMascot.jsx` 把格子裁成独立的 nested SVG。每次点击使用对应的完整表情素材，稳定时只显示一个云朵；表情交接为 100ms，回弹、呼吸和动作位移由 `transform`、`opacity` 和 Web Animations 连续插值。生气帧右上角的小符号单独裁出微动，最后两次点击保持相同的轻微生气表情。

路牌还原使用点击图集的 8 帧回弹，合计 220ms。第七次点击使用散开图集的 8 帧，合计 280ms，最后一帧完全透明。序列每帧保持到下一帧，避免逐帧淡出造成闪烁。还原过程中继续点击或记账会立即切入新动作；路牌仍支持两次点击或从第七次点击起 7 秒自动还原。

收支图集同时保存了完整分镜。运行时只裁出其中的钱束素材，沿连续曲线飞出或接住；哭脸、眼泪和手势保持独立动画。支出为 860ms，收入为 1040ms，不叠加第二张云朵或第二捆钱。

素材由内置 `image_gen` 生成，随后移除生成器烘焙的中性棋盘格并保留真实透明通道。不要把整张 atlas 当作按钮背景，也不要在图片里写入金额、文案或业务状态。

验证：`node tests/mascot-motion.browser.cjs` 覆盖表情可见性、逐帧连续显示、眼泪运动、天气配件、快速连点、两次点击还原、自动还原和卸载清理。手机确认按钮另见 `tests/confirm-touch.browser.cjs`。
