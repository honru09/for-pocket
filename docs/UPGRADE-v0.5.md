## Life360 对齐范围

对齐的是**圈子组织、邀请、成员与管理员关系**，产品仍是记账。地图、位置追踪、驾驶、订阅与安全服务不属于此次需求。

- 邀请码由现有成员分享，72 小时失效，预览成员后接受或取消。[官方加入流程](https://support.life360.com/hc/en-us/articles/23053441527319-Join-a-Circle)
- 可有多管理员；成员可邀请，管理员可移除成员、任命管理员、改圈名。系统上限为 99 人，官方建议最多 10 人，因此移除旧方案的固定四人限制。[官方权限](https://support.life360.com/hc/en-us/articles/23053644791447-Circle-Admin-and-Member-Permissions)
- 退出需确认；最后一位管理员退出时自动交接。[官方退出流程](https://support.life360.com/hc/en-us/articles/23053397900439-Leave-a-Circle)

账单权限是本产品规则：作者可删除自己的圈内记录，管理员可删除圈内记录。个人账本及各圈子独立；移除/退出后立即失去访问权限，旧邀请码同时失效。

## 首页原则

保持“金额 → 用途 → 保存”。个人账本隐藏成员选择，默认本人；共享账本只增加紧凑的成员选择器。首页只显示今日支出，收入、支出、净额放在账本。管理与登录说明只出现在二级页面。

保留纸色、吉祥物与 TelegramUI 组件。动效采用短距离 transform / opacity，支持系统减少动态效果与键盘即时输入。

## 数据与发布

### 追加界面修正

支持补记与修改旧账时间：新增 occurredAt 作为发生时间，保留 createdAt 作为创建时间。旧记录缺少 occurredAt 时使用原 createdAt。修改时间沿用记录者/圈子管理员权限，归组与排序按发生时间更新。

默认头像新增小黄云，旧猫图标改成圆润线条。输入框聚焦去掉硬边方框，用柔和背景与底线提示。顶部切换、日期和今日账本入口使用 SVG 图标，修正 TelegramUI 按钮内容布局。

原始文件保留，新状态写入 `_pocket-v2.json`。旧固定名字只作为历史快照保留，避免把旧账擅自归给真实用户。

本次完成本地实现、构建与验证；发布准备补齐后同步到 `release/v0.5.0`。用户决定保持 Render 免费实例、暂不部署，所以 main 与线上旧版保留。Google 真实登录需 OAuth client 与授权 origin；自动化使用隔离认证 fixture 验证流程，不能替代真实 OAuth 验收。

追加发布工具：Linux / Windows CI、Render 可选持久盘蓝图、备份与 SHA256 校验恢复、只读 Render 审计、bot 菜单配置/检查、健康接口版本和 commit、真实资产验收。交接计划已移除旧版固定角色、四人圈与启动自动配置菜单等错误说明。
